# Змейка (Snake Game) для Android

Простая классическая игра «Змейка» на Kotlin.

## Как собрать APK

1. Скачайте или клонируйте этот репозиторий
2. Откройте проект в **Android Studio**
3. Дождитесь синхронизации Gradle
4. Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`

Можно установить на телефон и играть.

## Управление
- Свайпы влево / вправо / вверх / вниз
